# Evidence grades

Every generated skill records the grade of the source it was built from, in the design brief and in
the usage guide's Provenance section. The grade tells a user how much weight the method carries before
they rely on it.

| Grade | Source type | Examples |
|---|---|---|
| **A** | Official guidelines and consensus standards issued by a standards body or professional society | CHEERS 2022, NICE methods guide, PRISMA 2020 |
| **B** | Peer-reviewed articles, including methods papers and reporting guidelines published in journals | A methods paper introducing an estimator; a journal-published checklist |
| **C** | Expert opinion and established practice | Textbooks, widely used tutorials, documented team procedures |
| **D** | Preprints, working papers, blogs, and other unreviewed material | arXiv or SSRN preprints, technical blog posts |

When a source mixes types, grade the part the skill applies. When a later version of the source exists,
say which version the skill implements and why.
