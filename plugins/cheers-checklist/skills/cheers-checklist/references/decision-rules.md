# CHEERS 2022 audit — states, decision rules, evidence standards

Source: Husereau D, Drummond M, Augustovski F, et al. CHEERS 2022 Statement. *Value Health* 2022;25(1):3–9, doi:10.1016/j.jval.2021.11.1351 (CC BY 4.0), with Appendix A (GRIPP2 short form, `mmc1.docx`) and Appendix B (Delphi protocol, `mmc2.docx`). `P<n>/J<n>` = PDF page / journal page (P1 = J3).

R-rules quote the sources. S-rules are this skill's own interpretation where the sources are silent; say "skill rule" when you rely on one in a report.

## 1. State definitions (S1)

One state per item, 28 items.

| State | Definition | The row must carry |
|---|---|---|
| **Addressed** | Every applicable clause of the item's guidance (see the clause list in `cheers-checklist.md`) is present in the main document or a supplied supplement. | A verbatim quote and its locator. |
| **Partially addressed** | At least one applicable clause is present and at least one is absent. Typical: perspective stated without "why chosen" (8); horizon without "why appropriate" (9); currency without price year (15); model described without the public-availability statement (16); discussion without "ethical or equity considerations not captured" (26). | Quote, locator, and the absent clause named. |
| **Missing** | Nothing found in any supplied file for an item that applies. In the submission table this is "Not reported" (R15). | The verbatim guidance in the closing section. |
| **Not applicable** | Only under R14 (study-type examples) or S2 (conditional items with an explicit not-undertaken statement). | The rule id and the document's justification quote, or "no justification given". |

Tally = plain counts of the four states over the 28 items (S9). No score, percentage, weight, rank, severity tier or pass/fail: CHEERS 2022 has "no validated scoring system" and scoring "is strongly discouraged" (R7).

## 3. Applicability conditions in the item wording (R29–R36)

| # | Item wording | Consequence |
|---|---|---|
| R29 | 4 "Indicate whether a health economic analysis plan was developed and where available." | "No plan was developed" → Addressed (S3). Plan mentioned without location → Partially addressed. Silence → Missing. |
| R30 | 16 "If modelling is used, describe in detail and why used. Report if the model is publicly available and where it can be accessed." | Non-modelling → Not applicable (R14). Modelling → clauses: detailed description; why used; availability and where ("not publicly available" answers "Report if"). |
| R31 | 17 "any methods for analysing or statistically transforming data, any extrapolation methods, and approaches for validating any model used." | Audit each clause only when its activity occurs; validation only when a model is used. |
| R32 | 18 "Describe any methods used for estimating how the results of the study vary for subgroups." | Explicit "no subgroup analyses" → Not applicable (S2). Silence → Missing. |
| R33 | 21 "Describe any approaches to engage …"; 25 "Report on any difference … involvement made …". | Explicit "no patients/public/stakeholders were involved" → 21 and 25 Not applicable (S2). Engagement described → both apply. Silence → both Missing. |
| R34 | 24 "Report the effect of choice of discount rate and time horizon, if applicable." | Second sentence applies when discounting is used or the horizon choice could change the result; the first sentence always applies. |
| R35 | 11–13 for cost analyses (R14). | Cost analysis → Not applicable. |
| R36 | 22 for non-modelling studies (R14). | Empirical study without a model → Not applicable, even if a cost table is given (add a note in the row). |

## 4. Skill rules (S1–S9)

| # | Rule |
|---|---|
| S1 | Four states as in §1. |
| S2 | Not applicable only (a) under R14's examples (11–13 cost analysis; 16, 22 non-modelling), or (b) for items with conditional wording — 16, 17 (per clause), 18, 21, 25, and 24's second sentence — when the document explicitly states the activity was not undertaken (quote it). Silence → Missing. An author's "not applicable" for an item without conditional wording (for example 19, 20, 26) is **not** accepted: report Missing (or Partial if some content exists) and quote the claim in "What is absent". |
| S3 | A "none / not done" statement that literally answers an unconditional item counts as Addressed: "no analysis plan was developed" (4); "costs were not discounted because the time horizon was 12 months" (10, rate and reason both given); "no currency conversion was needed" (15, year-of-conversion clause). |
| S4 | Study type: `--modelling`/`--form` argument > declaration in the document > vocabulary inference (`study-type-detection.md`). One confirmation question when inferred; after "just do it", proceed and write "inferred, user said proceed". |
| S5 | Stop and do not audit when R1 or R4 excludes the document (`study-type-detection.md` §1). |
| S6 | Evidence standards (§5). |
| S7 | Cross-checks (§6). |
| S8 | Addressed / Partial is decided clause by clause, using the clause list in `cheers-checklist.md`. Item 19 has two alternatives joined by "or" — either one satisfies it. Clauses with a condition are audited only when the condition holds. |
| S9 | Tally over 28 items, plain counts only. |

## 5. Evidence standards (S6)

- Quote the audited document verbatim, in its own language (English or Spanish), long enough to show the clause is met. A table or figure counts: cite its number and file.
- Locator = file role and name from the corpus markers + page (PDF) or heading (DOCX/MD) + table/figure number. Supplements are valid locators (R17).
- A link to material that was not supplied cannot be read: the clauses that depend on it are Partially addressed ("content behind link not supplied"). Exception: the location clauses of item 4 ("where available") and item 16 ("where it can be accessed"), where the link or repository is itself the evidence. "Available from the authors on request" satisfies only those two location clauses.
- Copy CHEERS guidance only from `cheers-checklist.md` or the skeleton; never paraphrase it in the "CHEERS 2022 guidance" column or the closing section; never translate it (R27).
- Do not judge methods or results (R8): a 1.5% discount rate with a reason is Addressed; whether 1.5% is appropriate is not your question.

## 6. Cross-checks (S7)

Fill the cross-check table in the report; flag inconsistencies, do not change states because of them.

| Pair | Check |
|---|---|
| 20 ↔ 24 | Uncertainty methods in 20 have their effect on findings in 24 (and the reverse). |
| 9, 10 ↔ 24 | If discounting is used or the horizon choice matters, 24 reports the effect of discount rate and time horizon. |
| 21 ↔ 25 | Engagement in 21 → its effect in 25; explicit no engagement → both N/A; silence → both Missing. |
| 16 ↔ 17 ↔ 22 | Study type used consistently (modelling → 16, 22 and 17's validation clause apply). |
